## Tech
Single-file, dependency-free static site — semantic HTML, modern CSS (custom properties, grid, light/dark theming), and a touch of vanilla JS for the theme toggle and scroll reveals. Fast, accessible, and hosted on GitHub Pages.

```
index.html      # the entire site
profile.jpg     # optimized hero image
resume.pdf      # downloadable résumé
favicon.ico
```
