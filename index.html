Aadi AI CRM

Founder & Product Architect · full-stack SaaS + operator control plane

An open, agent-native CRM designed to be driven by your existing AI assistant (Claude, ChatGPT, Cursor, Gemini) through the Model Context Protocol. GUI, REST API, and MCP all call the same domain services — so an agent can do everything a human can, under identical RBAC, tenant-scoping, and audit. Shipped alongside Studio Control Plane, a separate two-plane operator console for running it as a SaaS business (tenants, billing, licensing, health, compliance).

  • One tool surface: GUI + REST (/api/v1) + MCP (/api/mcp) over shared services — agent parity by construction
  • Tenant-safe by design: every row carries companyId; cross-tenant access is indistinguishable from not-found
  • Audited by default — every mutation writes an append-only entry with actor + source (gui/api/mcp)
  • Self-hostable via Docker Compose; contract-first two-plane split between app and control plane

◆ Enterprise PaaS Private — walkthrough on request

SAM — Skill Assessment Module

Product & Architecture Lead · enterprise multi-tenant talent PaaS

An enterprise multi-tenant Talent-Management Platform-as-a-Service. Organizations model their people (Org → Departments → Roles → Users), distribute competency assessments via unguessable magic links, inject proprietary grading rubrics per role, and review readiness analytics that roll up from the individual all the way to the whole company. Runs dual-mode — fully local (Ollama/Qwen, zero data egress) or serverless on Google Cloud Run with Gemini grading.

  • Bottom-up analytics: Individual → Team → Department → Company, with per-skill gap analysis
  • Hardened auth: bcrypt + signed JWT, strict token-derived actor, tenant-scoped 403s, server-side logout revocation
  • Identity assurance for candidates: honor-code attestation + email-OTP anti-proxy verification
  • Content-agnostic assessment engine with adaptive 80/20 selection; authored bank of 3,216 questions

Tithiya

Founder & Product Lead · cross-platform consumer app (iOS + Android)

A shipped, cross-platform mobile app — a modern Hindu Panchang, Vrat & festival calendar.
